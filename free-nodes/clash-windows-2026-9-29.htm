准备工作：谷歌云账号与基础认知

在动手之前，你需要准备以下几样东西：

  1. 一个谷歌云账号：访问 cloud.google.com，用你的Google账号注册即可。新用户通常会获得300美元的免费试用额度，足够你折腾很久。
  2. 一张支持国际支付的信用卡：用于验证身份。谷歌云会预扣少量费用（通常1美元左右）验证卡片有效性，随后会返还。
  3. 基础的Linux命令行知识：不需要精通，但至少要知道ssh、sudo、vim这些命令是干嘛的。如果你完全没接触过，也别慌，我会把每一步都写清楚。

小提示：如果你对成本敏感，记得在创建实例后设置预算警报，避免意外扣费。

第一步：在谷歌云上创建你的虚拟服务器（Compute Engine）

1.1 进入控制台并创建实例

登录谷歌云控制台，在左侧菜单中找到 “Compute Engine”（计算引擎），点击进入后选择 “VM 实例”（虚拟机实例）。点击 “创建实例” 按钮，开始配置你的第一台云服务器。

1.2 配置实例参数

  • 名称：给你的服务器起个名字，比如 my-v2ray-proxy。这个名字只是内部标识，不影响任何功能。
  • 区域：这是最关键的一步。谷歌云在全球有多个区域，比如美国、欧洲、亚洲等。选择区域时，建议考虑两个因素：
    • 物理距离：离你越近，延迟越低。如果你在中国大陆，可以选择台湾、香港或新加坡机房（如果有的话）；如果你在北美，选择美国中部或西部。
    • 网络稳定性：一些区域（如asia-east1台湾）在跨境连接上表现更优。如果只是用于日常翻墙，建议选择香港或新加坡，延迟和丢包率都相对理想。
  • 机器类型：初学者选择 “f1-micro” 就足够了（共享vCPU + 0.6GB内存），完全能跑V2Ray。如果你需要更高的并发连接，可以升级到e2-small或e2-medium。
  • 操作系统：推荐选择 Ubuntu 22.04 LTS 或 Debian 11。这两个系统对V2Ray的支持最好，且社区教程丰富。我建议选Ubuntu，因为后续安装软件更简单。
  • 防火墙规则：在“防火墙”部分，务必勾选“允许HTTP流量”和“允许HTTPS流量”。虽然V2Ray默认使用自定义端口（如10086），但开放HTTP/HTTPS端口有助于后续配置WebSocket+TLS伪装时使用。

1.3 创建并连接

点击“创建”后，谷歌云会自动分配一个公网IP地址。等待几十秒，实例状态变为“绿色勾选”后，你就可以通过SSH连接了。

在实例列表中，点击SSH按钮旁边的下拉箭头，选择“在浏览器窗口中打开”即可直接进入终端——这是谷歌云提供的Web SSH，无需额外配置密钥，非常方便。

第二步：安装V2Ray——从命令行到运行

2.1 更新系统包

连接上服务器后，第一件事是更新软件包列表：

bash sudo apt update && sudo apt upgrade -y

2.2 下载并安装V2Ray

V2Ray官方提供了一键安装脚本，但为了更可控，我推荐手动安装。首先，访问V2Ray的GitHub发布页面（github.com/v2fly/v2ray-core/releases），找到最新版本的Linux 64位压缩包。你也可以直接在终端执行：

```bash

下载最新版（以v5.x为例）

wget https://github.com/v2fly/v2ray-core/releases/latest/download/v2ray-linux-64.zip

安装解压工具（如果未安装）

sudo apt install unzip -y

解压到/usr/local/v2ray目录

sudo mkdir -p /usr/local/v2ray sudo unzip v2ray-linux-64.zip -d /usr/local/v2ray

赋予执行权限

sudo chmod +x /usr/local/v2ray/v2ray ```

2.3 配置系统服务

为了让V2Ray在后台稳定运行，我们需要将其注册为systemd服务。创建一个配置文件：

bash sudo vim /etc/systemd/system/v2ray.service

输入以下内容：

```ini [Unit] Description=V2Ray Service After=network.target

[Service] ExecStart=/usr/local/v2ray/v2ray run -c /usr/local/v2ray/config.json Restart=on-failure RestartSec=3

[Install] WantedBy=multi-user.target ```

保存并退出（vim中按Esc，输入:wq回车）。然后启动服务并设置开机自启：

bash sudo systemctl daemon-reload sudo systemctl enable v2ray sudo systemctl start v2ray

第三步：配置V2Ray——让流量安全地流动

3.1 生成UUID和密钥

V2Ray需要UUID（用户唯一标识）和传输密钥。在服务器上执行：

```bash

生成UUID

cat /proc/sys/kernel/random/uuid

生成随机端口（例如10086）

echo $((RANDOM % 60000 + 1024)) ```

记下输出的UUID和端口号，我们马上要用。

3.2 编写配置文件

V2Ray的配置文件是JSON格式，位于/usr/local/v2ray/config.json。我们创建一个基础但功能完整的配置：

bash sudo vim /usr/local/v2ray/config.json

粘贴以下内容（记得替换your-uuid-here为刚才生成的UUID，10086为随机端口）：

json { "inbounds": [ { "port": 10086, "protocol": "vmess", "settings": { "clients": [ { "id": "your-uuid-here", "alterId": 0 } ] }, "streamSettings": { "network": "tcp", "security": "none" }, "sniffing": { "enabled": true, "destOverride": ["http", "tls"] } } ], "outbounds": [ { "protocol": "freedom", "settings": {} } ] }

解释一下：这个配置创建了一个VMess协议的入站代理，监听10086端口，任何知道UUID的客户端都可以连接。出站设置为freedom，即直接访问目标网站。这是最基础的配置，适合快速测试。后续你可以添加TLS加密、WebSocket伪装等高级功能。

保存并退出，然后重启V2Ray使配置生效：

bash sudo systemctl restart v2ray

3.3 验证运行状态

执行以下命令检查V2Ray是否正常运行：

bash sudo systemctl status v2ray

你应该看到active (running)字样。如果没有，可以查看日志：

bash sudo journalctl -u v2ray -n 20

第四步：本地客户端连接——让流量从你的电脑出发

4.1 下载客户端

在本地电脑上，根据你的系统下载对应的V2Ray客户端：

  • Windows：推荐V2RayN或v2rayA
  • macOS：推荐V2RayX或V2RayU
  • Android：V2RayNG
  • iOS：Shadowrocket或Kitsunebi

4.2 添加服务器配置

以V2RayN为例，打开软件，点击“服务器” -> “添加VMess服务器”，填写：

  • 地址：你的谷歌云公网IP
  • 端口：你设定的10086
  • 用户ID：你生成的UUID
  • 额外ID（alterId）：0
  • 传输协议：tcp
  • 伪装类型：none

保存后，右键点击服务器列表中的节点，选择“设为活动服务器”。然后点击主界面右上角的“系统代理” -> “自动配置系统代理”。浏览器打开谷歌搜一下，看看能否正常访问。

第五步：进阶优化——让V2Ray更安全、更快速

5.1 启用TLS加密和WebSocket伪装

裸的VMess流量虽然加密，但在深度包检测（DPI）面前仍可能被识别。通过配置TLS和WebSocket，可以将V2Ray流量伪装成普通的HTTPS网站访问，大大降低被封锁的概率。

这需要你拥有一个域名，并申请免费的Let's Encrypt证书。步骤略复杂，但值得投资。具体配置可以参考V2Ray官方文档，这里只提核心思路：

  • 在DNS服务商（如Cloudflare）将域名解析到你的谷歌云IP。
  • 安装Caddy或Nginx，配置反向代理，将https://你的域名/ws路径转发到V2Ray的10086端口。
  • 修改V2Ray配置，将streamSettings.network改为ws，并添加tls对象。

5.2 启用系统防火墙

虽然谷歌云提供了网络防火墙规则，但建议在系统内部也开启ufw，只放行SSH和V2Ray端口：

bash sudo ufw allow 22/tcp sudo ufw allow 10086/tcp sudo ufw enable

5.3 定期更新

V2Ray迭代很快，建议每月执行一次更新，获取性能改进和安全修复。

FAQ：常见问题解答

Q1：谷歌云免费试用到期后，如何避免高额账单？ A：在“计费”页面设置预算提醒，并在不需要时删除实例。如果你只是偶尔使用，可以选择“抢占式”实例，价格便宜80%，但可能被谷歌随时回收。

Q2：搭建的V2Ray速度很慢，怎么办？ A：首先检查选择的区域是否离你较远。其次，尝试更换传输协议为kcp或grpc，有时能提升速度。最后，检查本地网络是否对UDP限速。

Q3：连接总是断开，日志显示“connection reset” A：这通常是因为防火墙拦截了长连接。检查谷歌云网络防火墙是否允许TCP端口，并在本地系统防火墙中放行。

Q4：能否用谷歌云搭建其他代理工具，比如Shadowsocks？ A：当然可以。谷歌云是通用计算平台，你可以安装任何软件。但V2Ray在抗封锁和灵活性上更胜一筹。

Q5：谷歌云会封禁搭建代理的账号吗？ A：谷歌云的服务条款禁止滥用，包括搭建非法代理。但实际执行中，只要你的流量不过分异常，通常不会主动封号。建议使用TLS加密，并确保流量符合正常HTTPS特征。

可以。Surfboard 支持 iCloud 同步功能，用户可在不同苹果设备上共享同一配置文件。这样即使更换手机或重装系统，也能自动恢复节点与分流设置。
Nekoray 的订阅更新机制如何运作？
Nekoray 可以通过远程订阅 URL 自动下载最新节点和规则文件。用户可以设置更新频率，程序会定时检测并替换旧节点，保持配置最新状态。
Netch 的 TAP 模式与 TUN 模式区别是什么？
TAP 模式模拟以太网接口，适合游戏流量代理；TUN 模式则模拟 IP 层接口，更适合全局代理。根据用途不同可自由选择，但需管理员权限运行。
